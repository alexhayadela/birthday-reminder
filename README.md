# Birthday Reminder

A small Python automation that checks birthdays stored in Supabase and sends a daily email reminder when someone's birthday is two days away.

The email also includes the next four upcoming birthdays.

## How it works

Every day, GitHub Actions runs the application:

1. Fetch people and their birthdays from Supabase.
2. Calculate each person's next birthday.
3. Find birthdays exactly two days away.
4. If there is a reminder, build an email containing:

   * The birthday reminder.
   * The next four upcoming birthdays.
5. Send the notification by email.

The notification layer is separated from the birthday logic so another channel, such as WhatsApp, can be added later without changing the birthday calculation.

## Requirements

* Python 3.13
* A Supabase project
* A Gmail account or another SMTP-compatible email account
* GitHub Actions for scheduled execution

## Database

The application uses a single Supabase table called `people`.

Run the following SQL in the Supabase SQL Editor:

```sql
create table if not exists people (
    id bigint generated by default as identity primary key,
    name text not null,
    birthday_month smallint not null
        check (birthday_month between 1 and 12),
    birthday_day smallint not null
        check (birthday_day between 1 and 31)
);
```

Only the month and day are stored because the year of birth is not required.

Example:

```text
id | name  | birthday_month | birthday_day
---+-------+----------------+-------------
1  | Anna  | 9              | 27
2  | Marc  | 10             | 1
3  | John  | 12             | 14
```

## Local configuration

Create:

```text
conf/.env
```

with:

```env
SUPABASE_URL=your_supabase_url
SUPABASE_API_KEY=your_supabase_api_key
EMAIL_USER=your_email@gmail.com
EMAIL_PASSWORD=your_email_password
```

Do not commit this file.

For Gmail, `EMAIL_PASSWORD` should normally be an **App Password**, not your normal Google account password.

## Install

Create a virtual environment:

```bash
python3.13 -m venv .venv
```

Activate it:

### macOS / Linux

```bash
source .venv/bin/activate
```

### Windows

```powershell
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run locally

Run:

```bash
python -m src.main
```

The application will check the database and send an email if someone has a birthday exactly two days from today.

## GitHub Actions

The workflow runs every day at 08:00 UTC.

It can also be started manually using the `workflow_dispatch` option in GitHub Actions.

The following GitHub repository secrets are required:

```text
SUPABASE_API_KEY
SUPABASE_URL
EMAIL_USER
EMAIL_PASSWORD
```

The workflow passes these values to the application as environment variables.

## Reminder logic

If today is September 25 and the database contains:

```text
Anna  — September 27
Marc  — September 28
John  — October 1
Sarah — October 14
```

the email contains:

```text
🎂 Birthday reminder

Anna has a birthday in 2 days (Sunday, 27 September).

📅 Next birthdays

Anna  — Sunday, 27 September (2 days)
Marc  — Monday, 28 September (3 days)
John  — Thursday, 1 October (6 days)
Sarah — Wednesday, 14 October (19 days)
```

If nobody has a birthday exactly two days away, no email is sent.

## Future notification channels

The notification interface is intentionally separated from the pipeline.

Currently:

```text
pipeline
    ↓
notifier
    ↓
email
```

A future implementation could use:

```text
pipeline
    ↓
notifier
    ↓
WhatsApp
```

without changing the birthday calculation logic.
